# AI × Web3 School - Personal Learning Journal

> 个人学习仓库，用于记录 AI × Web3 School 的学习过程、项目进展与打卡证明。

## 课程入口

- **Handbook**：https://aiweb3.school/zh/handbook/
- **WCB 课程页面**：https://web3career.build/zh/programs/AI-Web3-School
- **WCB Learning 页面**：https://web3career.build/zh/programs/AI-Web3-School#tab=learning

## 仓库说明

本仓库为公开仓库（public），用于沉淀学习笔记、项目和反馈。

**隐私提醒**：请勿在此仓库中存放任何敏感信息，包括但不限于：
- API Key、私钥、助记词
- 个人联系方式
- 内部会议链接
- 未公开的项目资料

## 目录结构

- `daily/`：每日学习笔记与打卡记录
- `tasks/`：任务拆解与进度追踪
- `experiments/`：实验、代码尝试与小项目
- `handbook-feedback/`：Handbook 问题反馈与建议
- `hackathon/`：Hackathon 项目相关资料
- `submissions/`：作业提交记录
- `templates/`：笔记模板
